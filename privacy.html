Project Edge プライバシーポリシー

最終更新日：2026年10月18日

このツールについて

Project Edge は、開発者本人が自分の株式投資を記録・点検するための個人用ツールです。利用者は開発者本人だけです。

使う情報

  • Google アカウントのメールアドレス：開発者本人へレポートのメールを送る宛先として使います。
  • 開発者本人の Google スプレッドシート：投資の記録と、公開されている決算・株価の情報を保存します。

情報の扱い

  • 取得した情報を、開発者本人以外の第三者に提供・販売しません。
  • 広告や分析のために使いません。
  • 情報は開発者本人の Google アカウントの中（スプレッドシート・メール）にだけ保存されます。

Google ユーザーデータの扱い

Google API から受け取った情報の利用と他のアプリへの移転は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。
